개인정보처리방침

적용 대상: 개인용 Google Calendar 연결 도구 Jion Calendar와 그 안내 페이지. 이 문서는 현재 구현 범위와 정보 처리 방식을 설명합니다.

1. 접근하고 처리하는 정보

  • Google 캘린더 ID, 표시 이름, 시간대, 기본 캘린더 여부와 소유 권한
  • 사용자가 입력하고 등록을 승인한 일정의 제목, 시작·종료, 장소 및 설명
  • 중복 등록 방지와 결과 확인에 필요한 일정 ID, 승인 기록, 해시 및 처리 결과
  • Google API 연결을 위한 OAuth 액세스 토큰·갱신 토큰과 앱 연결 설정

캘린더 전체 일정 내용을 상시 수집하지 않습니다. 현재 기능은 소유 캘린더 목록과 등록 대상 단일 일정의 확인에 한정됩니다.

2. 이용 목적과 처리 경로

정보는 사용자가 요청한 일정 준비·확인·등록, 정확한 결과 검증, 인증 유지 및 중복·오류 방지를 위해 처리합니다. Google API와의 통신에는 HTTPS를 사용합니다.

사용자의 일정 관련 입력이나 필요한 조회 결과는 AI 비서 요청을 처리하는 과정에서 OpenClaw 및 사용자가 연결한 모델 제공자에게 전달될 수 있습니다. 해당 서비스의 보관·처리 조건은 사용자가 이용하는 서비스 설정과 계약을 따릅니다. 모든 처리가 맥 안에서만 이루어진다고 주장하지 않습니다.

인증 토큰과 앱 비밀값은 공개 페이지나 AI 대화 출력에 포함하지 않도록 구현되어 있습니다. 이 도구는 Google 사용자 데이터를 광고·판매 또는 범용 AI 모델 학습 목적으로 사용하지 않습니다. Google API에서 받은 정보는 Google API Services User Data Policy와 제한적 사용 요건에 따라 취급합니다.

3. 저장 위치와 보유 기간

OAuth 인증정보는 운영자의 맥 로컬 파일에 운영자 접근만 허용하는 파일 권한으로 저장합니다. 현재 이 파일 저장 방식은 Keychain 저장이나 파일 자체 암호화가 아닙니다.

승인 기록과 처리 영수증은 운영자의 로컬 환경에 남을 수 있습니다. 승인 유효기간이 지나도 기록 파일이 자동 삭제되는 것은 아닙니다. Google에 등록된 일정은 사용자가 별도로 삭제할 때까지 Google 계정에 유지되며, Google 및 연결한 AI 서비스의 기록에는 각 서비스의 보관 정책이 적용됩니다.

4. 공유 및 접근 제한

현재 도구는 일정에 참석자를 추가하거나 다른 사람을 초대하지 않습니다. 생성 일정은 비공개로 설정하며, 캘린더 공유 설정을 바꾸지 않습니다. 다만 기존 캘린더 관리자 등에게 적용되는 Google의 접근 규칙은 Google Calendar 정책을 따릅니다.

필요한 Google API 처리와 사용자가 선택한 AI 비서 서비스를 제외하고, 이 도구에는 데이터 판매·광고 제공·데이터 중개 기능이 없습니다. 운영자는 장치와 연결한 서비스의 접근 권한을 관리합니다.

5. 연결 해제와 삭제

사용자는 Google 계정의 연결 관리에서 앱 접근을 철회할 수 있습니다. 접근 철회만으로 이미 등록된 일정이나 로컬 기록이 삭제되지는 않습니다. 일정은 Google Calendar에서, 로컬 인증정보·승인 기록은 맥의 개인 저장 위치에서 운영자가 별도로 관리·삭제해야 합니다.

6. 이 안내 사이트

이 정적 안내 페이지에는 자체 분석 도구, 광고, 입력 양식, 추적 스크립트 또는 자체 쿠키를 넣지 않습니다. 이 안내 사이트는 GitHub Pages에 호스팅됩니다. GitHub는 로그인 여부와 무관하게 방문자의 IP 주소를 보안 목적으로 기록·저장합니다. 자세한 내용은 GitHub 개인정보처리방침을 확인해주세요.

7. 문의와 변경

문의 및 데이터 관리 요청은 이 앱을 설정한 개인 운영자에게 전달해주세요. 지원 연락처는 Google 동의 화면에 표시한 사용자 지원 이메일을 따릅니다. 기능, 처리 서비스 또는 저장 정책이 바뀌면 이 문서를 업데이트합니다.
